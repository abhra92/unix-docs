# Core commands cheatsheet

## Files and directories

```bash
ls -la
cp -av source/ target/
rsync -avz --delete source/ target/
```

## Processes

```bash
ps aux | sort -nrk 3 | head -n 5
kill -TERM <pid>
```

## Networking

```bash
ss -tulpen
curl -I https://example.com
```
